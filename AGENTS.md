# Tech demos

- Put one app per approved pick under `apps/<slug>/`.
- Every app must be self-contained: `bun install && bun run dev` must work from its folder.
- Every pull request must include at least one screenshot and at least one video of the running app.
- After the initial monorepo layout, agents may only add or update their assigned `apps/<slug>/`.
- Never create a separate repository for a demo.
