# Project planning

Before implementation, write a short `PLAN.md` that records:

1. **Goal** — the user-visible outcome and the command that proves it runs.
2. **In scope** — the smallest set of features required for the demo.
3. **Out of scope** — adjacent work this demo intentionally does not take on.
4. **Stack** — runtime, framework, and important integrations.
5. **Validation artifacts** — automated checks plus at least one screenshot and one video of the running app.
